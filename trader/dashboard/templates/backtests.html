Run a backtest

Backtests are run from the command line (not the UI, to avoid long-running web requests). SSH to the droplet and run: 

cd /opt/trader
sudo -u trader .venv/bin/python -m trader backtest --strategy {{ cfg.strategy.name }} --start 2018-01-01 --end 2024-12-31

The HTML report will appear in this list within a few seconds.
