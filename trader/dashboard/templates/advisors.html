Service Setup

Initial advisor service: AI Hedge Fund. The upstream project is educational and does not place trades. Run it as a separate service or cron job, then write JSON to the path above. 

cd /opt
sudo git clone https://github.com/virattt/ai-hedge-fund.git
sudo chown -R trader:trader ai-hedge-fund
cd /opt/ai-hedge-fund
sudo -u trader poetry install
# Expected dashboard output file:
mkdir -p /opt/trader/data/advisors

# JSON shape the dashboard reads:
{
  "generated_at": "2026-05-03T00:00:00+00:00",
