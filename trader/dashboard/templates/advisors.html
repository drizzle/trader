Security Model

  • Advisor LLM calls send only ticker symbols + computed price stats (returns, RSI, drawdown) to DeepSeek over HTTPS.
  • Your Alpaca API key never leaves the droplet. The advisor module uses the read-only Data client; it has no reference to the trading client.
  • The DeepSeek key is loaded from /opt/trader/.env (mode 600) and sent only as an HTTPS Bearer header.
  • Recommendations are cached for 1 hour to limit LLM spend. "Force fresh" bypasses the cache.
